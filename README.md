# 부서별 일일 예정사항 (A4 한 장 자동 맞춤)

`daily_schedule.html` 파일 하나로 동작합니다.
인터넷, 설치, 공유폴더가 없어도 **더블클릭해서 Edge로 열면 됩니다**(Chrome·웨일도 됩니다).
외부 라이브러리나 웹폰트를 쓰지 않고, 어디로도 데이터를 보내지 않습니다.

## 매일 하는 일 (공유폴더 없이, 메신저·메일로)

| 누가 | 무엇을 |
|---|---|
| 취합 담당 (처음 한 번) | 저장 ▾ → **부서 작성용 파일(.html) 만들기** → 그 파일을 각 부서에 메신저로 보내 둡니다. |
| 각 부서 (매일) | 부서 작성용 파일을 열어 부서·날짜를 고르고 작성한 뒤 **[보낼 파일 저장]**을 누릅니다. 저장된 `일일예정_2026-11-10_총무과.txt`를 메신저·메일로 보냅니다. 파일 대신 **[내용 복사]**해서 대화창에 붙여넣어도 됩니다. |
| 취합 담당 (매일) | 받은 파일이 다운로드 폴더에 모이면 **[받은 파일 가져오기]**를 누르고 여러 개를 한꺼번에 고릅니다(▾ → **폴더에서 찾기**로 다운로드 폴더를 고르면 알아서 찾습니다). 확인 창에서 **[가져오기]**만 누르면 부서별로 들어갑니다. |

- 파일을 하나씩 열어 복사할 필요가 없습니다.
- 받은 파일은 파일 이름이나 첫 줄(`# 부서명 @날짜`)로 부서를 찾습니다. 부서가 메모장으로 직접 쓴 `기획과.txt`도 됩니다.
- 같은 부서 파일이 여러 개면 날짜가 맞는 최신 파일을 고르고, 지난 날짜 파일은 체크를 빼 둡니다.
- 오늘 오후에 내일 것을 취합하는 경우처럼 받은 파일 날짜가 문서 날짜와 다르면, 문서 날짜를 바꿀지 확인 창에서 물어봅니다.
- 메신저로 글을 받았다면 ▾ → **붙여넣기로 넣기**에 여러 부서 글을 한꺼번에 붙여넣으면 됩니다.
- **접수 현황**(받음 / 직접 입력 / 비어 있음)과 아직 안 낸 부서가 보입니다. [목록 복사]로 독촉 메시지를 만들 수 있습니다.
- 가져온 뒤 마음에 들지 않으면 알림의 **[되돌리기]**를 누르세요.

## A4 한 장 자동 맞춤

- 내용 양에 맞춰 글자크기·줄간격·자간·항목 간격을 함께 조절해 A4 한 장을 꽉 채웁니다(기본 7~13pt).
- 내용이 적으면 표를 페이지 아래 끝까지 늘리고, 그래도 넘치면 빨간 테두리와 넘친 길이(mm)를 보여 줍니다.
- 레이아웃은 표 / 표 2단 / 제목형 / 제목형 2단 중에서 고르고, A4 세로·가로, 결재란, 하단 문구도 설정할 수 있습니다.

## 링크와 설명 팝업 (화면에서만, 인쇄되지 않음)

```
- 10:00 주간 업무보고 회의
  >> 안건: 예산안 검토, 인사 발령
  >> 자료: http://intranet/board/123
- 14:00 [시설 점검](http://intranet/fac/77)
- 16:00 보안 교육 http://intranet/edu/5
```

| 입력 | 화면에서 |
|---|---|
| 항목 바로 아래 `>> 설명` | 그 항목에 마우스를 올리면 설명 팝업이 나옵니다(점선 밑줄 표시). |
| 부서 내용 맨 위 `>> 설명` | 부서명에 마우스를 올리면 나옵니다. |
| `[글자](주소)` | 글자를 누르면 링크가 열립니다. |
| 항목 끝에 주소 붙이기 | 항목 전체가 링크가 되고, 주소는 인쇄되지 않습니다. |

- 완성본을 화면으로 돌려 보게 하려면 저장 ▾ → **배포용 보기 파일(.html)**을 보내세요. 받은 사람이 열면 편집 화면 없이 문서만 보이고, 링크와 팝업이 동작합니다.
- 인쇄 창에서 **PDF로 저장**한 파일에서도 링크는 눌립니다(팝업은 HTML에서만 됩니다).

## 입력 방법

| 입력 | 결과 |
|---|---|
| `- 회의` | ○ 회의 |
| `  - 참석: 과장` (앞에 2칸) | 하위 항목(-) |
| `○`, `□`, `※`, `·` 직접 입력 | 입력한 기호 그대로 |
| `1.`, `가.`, `①` | 번호 그대로 |
| `09:00 회의` | 줄 앞 시간 자동 굵게 |
| `**굵게**`, `__밑줄__`, `~~취소~~`, `==형광펜==`, `!!빨간 강조!!` | 글자 꾸밈 |
| `## 소제목`, `> 비고`, `---` | 소제목, 비고, 구분선 |
| 세로줄로 칸을 나눈 줄 (아래 예시) | 표 |

```
| 시간 | 내용 | 장소 |
|---|---|---|
| 10:00 | 계약심의 | 소회의실 |
```

- `Tab` / `Shift+Tab`: 들여쓰기 / 내어쓰기
- 목록 줄에서 `Enter`: 다음 기호가 자동으로 붙습니다. 빈 항목에서 한 번 더 누르면 목록이 끝납니다.

## 저장 (재부팅해도 남기려면)

브라우저 자동저장은 **새로고침 대비용**입니다. 재부팅하면 사라지므로 파일로 남기세요.

| 메뉴 | 용도 |
|---|---|
| 저장 (`Ctrl+S`) | 작업 파일(.json). [받은 파일 가져오기] ▾ → 저장해 둔 작업 열기로 이어서 작업합니다. |
| 배포용 보기 파일(.html) | 링크·설명 팝업이 되는 읽기 화면 |
| 텍스트(.txt)로 내보내기 | `# 부서명 @날짜`로 구분된 텍스트 |
| 부서 작성용 파일(.html) | 각 부서에 한 번 나눠 주는 작성 화면 |
| 매일 쓸 양식 파일(.html) | 부서 목록·서식만 담은 빈 양식. 바탕화면에 두고 매일 이 파일을 여세요. |

> 화면 위쪽에 `● 파일로 저장 안 됨`이 보이면 아직 파일로 저장하지 않은 상태입니다.
