## 파일 하나, 위쪽 메뉴로 두 화면

`일일예정사항.html` 하나에 **일일 예정사항**(임원 8명)과 **부서별 일일 예정사항** 두 화면이 들어 있습니다.

```
[ 일일 예정사항 ] [ 부서별 일일 예정사항 ]          [↔ 순서 바꾸기]   ← 위쪽 메뉴: 눌러서 화면 바꾸기
──────────────────────────────────────────────────────────────────
  고른 화면 (새 문서 · 붙여넣기 · 저장 ▾ · 인쇄 / PDF …)
```

- 비밀번호는 **한 번만** 넣습니다. 두 화면이 같은 비밀번호로 잠기고, 비밀번호를 바꾸면 두 화면이 함께 바뀝니다.
- 메뉴를 오가도 작업하던 내용은 그대로 있습니다. 메뉴에서 `←` `→`로도 바꿉니다.
- **열면 메뉴 맨 앞 화면이 먼저 나옵니다**(처음에는 일일 예정사항(임원)). 메뉴 순서는 오른쪽 **[↔ 순서 바꾸기]**를 누르거나, 메뉴를 끌어다 다른 메뉴 앞·뒤에 놓아 바꿉니다. 바꾼 순서는 이 브라우저에 남습니다.
- 두 화면은 서로 떨어진 칸에서 따로 돌아서, 단추·단축키(`Ctrl+V` 붙여넣기 등)·서식 설정이 섞이지 않습니다.
- **인쇄는 두 화면을 합쳐 한 번에** 합니다: 어느 화면에서 **[인쇄 / PDF]**·`Ctrl+P`를 눌러도(브라우저 메뉴의 인쇄도) **1쪽 일일 예정사항, 2쪽 부서별 일일 예정사항**이 나옵니다(메뉴 순서와 상관없이 이 차례). 쪽마다 A4 한 장이고 용지 방향은 각 화면의 서식 설정대로입니다. 'PDF로 저장'하면 두 쪽짜리 PDF 하나가 됩니다.
  - 배포용 보기 파일처럼 화면 하나만 든 파일은 그 화면 한 장만 인쇄합니다. `src/`의 화면 파일을 따로 열었을 때도 그 화면만 인쇄합니다.
- 예전 `daily_schedule.html`·`executive_schedule.html`을 쓰던 브라우저라면 자동저장된 내용을 이어받습니다: 임원은 그대로, 부서별은 처음 열 때 한 번(같은 폴더에 있던 것 → 없으면 하나뿐인 것). 예전 파일은 지워도 됩니다.

## 모든 시트 합쳐 붙여넣기 — 합본 시트

엑셀·한셀 파일은 문서 보안(DRM) 때문에 화면에서 직접 열지 않고, 한셀에서 복사해 화면에 붙여넣습니다. 두 화면(부서별·임원) 모두 같은 규칙입니다.

**공동편집용 양식**(부서별: 입력 탭 [엑셀 양식 만들기], 임원: [붙여넣기] ▾ → 공동편집용 엑셀 양식 만들기)에는 매크로 없이 수식만으로 되는 장치가 들어 있습니다.

- **각 시트 A1**: `="#"&MID(CELL("filename",A1),FIND("]",CELL("filename",A1))+1,99)` — `#` + 지금 시트 이름이 저절로 들어갑니다(시트 이름을 바꾸면 같이 바뀜). 2행이 머리글입니다.
- **맨 마지막 `합본` 시트**: 앞 시트들의 내용(시트 안의 표, 임원 맨 밑 표 포함)을 수식으로 모아 둡니다. **합본 시트만 전체 선택(Ctrl+A) → 복사 → 화면에서 Ctrl+V** 하면 끝입니다.
  - 시트 이름을 바꾸면 합본 수식이 같이 바뀌고, 시트를 지우면 그 자리는 빈칸이 됩니다. 시트 안에 줄을 넣거나 빼도 맞습니다(줄 번호로 가져옴).
  - 새로 만든 시트는 합본 맨 위 **새로 만든 시트 이름** 칸(3칸)에 시트 이름을 적으면 들어갑니다. 다른 시트를 복사해 만들면 A1 수식도 따라옵니다.
  - 시트마다 부서별 60줄·A~H칸, 임원 50줄·A~F칸까지 모읍니다. 넘치거나 적은 이름의 시트가 없으면 합본 5행에 `⚠ 확인:`이 나옵니다.
  - A1 수식이 계산되지 않는 프로그램(예: LibreOffice)에서는 합본이 양식을 만들 때의 시트 이름을 대신 씁니다.
- 합본 맨 위 `#안내` 부분과 `#작성방법` 시트는 화면이 알아서 뺍니다.

합본은 아래 모양입니다(직접 매크로로 쌓을 때도 이 모양으로 — 시트마다 A1부터 그대로, 시트 사이 한 줄).

```
#기획조정과                         ← ① 시트 A1: "#시트 이름" (그 줄의 다른 칸은 비움)
내용 | 날짜(괄호 안에 기입됨) | 비고(아스타로 표현) | 설명(…) | 링크(클릭하면 실행됨)   ← ② 2행 머리글
09:00 주간 업무보고 | | 참석: 각 과장 | |
예산안 제출 | 11.14. | | |
(빈 줄)
■ 이번 주 교육 일정                  ← ③ 시트 안의 표도 그대로 (빈 줄 → 표 제목 → 표 머리글 → 표 내용)
교육명 | 일자 | 장소 | 대상
청렴 교육 | 11.12. | 대회의실 | 전 직원
(빈 줄)                             ← 시트 사이 한 줄 띄움 (없어도 됨)
#총무과                             ← 다음 시트의 A1
내용 | 날짜(괄호 안에 기입됨) | 비고(아스타로 표현) | 설명(…) | 링크(클릭하면 실행됨)
14:00 소방 안전점검 | | 전 층 | |
```

1. **이름 줄**: A열 한 칸에 `#` + 시트 이름(`#` 뒤 띄어쓰기·`#(이름)`처럼 괄호는 있어도 없어도 됨). 부서별은 부서명, 임원은 시트 이름 그대로(직위 성명 — 성명이 들어 있으면 그 임원을 찾음). `[이름]`도 되고, 이름만 써도 아는 부서·임원이고 바로 아래가 머리글이면 알아봅니다. 처음 보는 부서명이면 새 부서로 받습니다.
2. **내용**: 각 시트에서 쓴 범위를 머리글 줄부터 그대로. 열 순서·열 이름은 시트 그대로 두면 됩니다(머리글의 `내용·시간·비고·※ 참고·설명·링크·성명…`으로 칸을 알아봄, 뒤에 `(…)` 설명이 붙어도 됨). 머리글에 **괄호**가 든 열(`날짜(괄호 안에 기입됨)`)은 내용 뒤 `( )` 안에 들어가고, 괄호 없이 `날짜`라고만 쓴 열은 문서 날짜의 줄만 고르는 데 씁니다.
3. **값**: 셀에 보이는 글자 그대로가 가장 좋습니다(한셀 `.Text`). 시간이 숫자(예: `0.375`)로 와도 `09:00`으로 읽습니다. 칸 안 줄 바꿈(Alt+Enter)은 그대로 두세요(복사하면 따옴표로 묶여 함께 옵니다). 병합된 칸은 첫 칸 값만 있으면 됩니다.
   - **형광펜**: 한셀에서 칠한 바탕색은 복사해도 따라오지 않습니다. 칠한 칸(또는 글자)은 매크로에서 `[[` `]]`로 감싸 넣으세요 — `[[주간 업무보고]]` → 화면에서 노랗게. 시간 칸은 감싸지 않고, 칸 안 줄 바꿈이 있으면 줄마다 감싸며, 줄 앞 `- `·`* ` 기호와 끝의 `@장소`는 괄호 밖에 둡니다(`- [[안건 보고]] @대회의실`). `==글==`은 형광펜으로 읽지 않습니다(한셀에서 `=`는 수식).
4. **표(부서별)**: 시트 안에서 일정 아래 빈 줄 하나, A열부터 표 제목(한 칸, 선택) → 표 머리글 → 표 내용. 다음 빈 줄에서 표가 끝납니다.
5. **빼도 되는 시트**: 작성방법·안내 시트, 숨긴 시트. 양식의 작성방법 시트는 A1이 `#작성방법`이라 같이 쌓아도 화면이 뺍니다. 아직 안 쓴 시트(머리글만)는 넣어도 됩니다 — "비어 있음"으로 빠지고 기존 내용은 그대로입니다.
6. **임원 맨 밑 표**: 이름 줄 `#맨 밑 표`(양식의 그 시트 A1) + 머리글 `표 이름 | 칸 | 칸 제목 | 줄 제목 | 내용`(`칸`·`줄 제목` 열은 없어도 됨) + 한 줄에 한 칸.

   ```
   #맨 밑 표
   표 이름 | 칸 | 칸 제목 | 줄 제목 | 내용
   인접회사활동 | 1 | A사 | | 10:00 사장 주간회의
                | 2 | B사 | | 임원 워크숍           ← 표 이름은 그 표 첫 줄에만 써도 됨
   휴가 | 1 | (제목 없음) | | 상무 한소영 오전 반차
   출장/방문 | 1 | | | 부사장 박서연: 부산지사 (14:00~17:00)
   근무 | 1 | 당직 | 주간 | 총무팀 과장
        | 1 |      | 야간 | 시설팀 대리            ← 같은 칸 번호를 한 번 더: 당직 칸을 가로줄로 나눔
        | 2 | 비상대기 | | 비서실장
        | 3 | 상황근무 | | 1조 김민호             ← 칸 번호 3: 그날은 근무가 3칸
   ```

   - 표는 이름(인접회사활동·휴가·출장/방문·근무, 화면에서 바꾼 이름도 됨)으로 찾습니다.
   - 칸은 칸 제목(회사명)이 화면의 칸 제목과 같은 칸 → 칸 번호 → 남은 칸 차례로 넣습니다. 붙인 표에서 빠진 칸은 비우고, 붙이지 않은 표는 그대로 둡니다. `(제목 없음)`은 제목 없이 넣습니다.
   - **근무**는 붙인 대로 칸 수가 정해집니다(칸 번호 3, 4…를 쓰면 칸이 늘고 최대 8칸, 2칸보다 적게 붙이면 기본 2칸). **같은 칸 번호를 한 번 더** 쓰면 그 칸이 가로줄로 나뉩니다(한 칸 6줄까지, 줄 순서는 시트에 쓴 차례 — 맨 아래에 덧붙여 써도 됨). **줄 제목**(주간·야간 등)은 그 줄 앞에 굵게 찍히고 비워도 됩니다. 칸 번호 없이 쓰면 칸 제목이 있는 줄은 새 칸, 줄 제목만 있는 줄은 바로 위 칸의 다음 줄입니다.
7. **이름 줄 없이** 붙이면 머리글 줄이 다시 나올 때마다 나누고, 넣을 부서·임원은 확인 창에서 고릅니다(처음에는 체크가 풀려 있음).
8. **붙여넣기**: 합친 범위를 복사 → 화면의 **[붙여넣기]** 창에 `Ctrl+V` → [다음] (또는 입력칸 밖에서 바로 `Ctrl+V`) → 확인 창에서 넣을 곳을 보고 **[가져오기]**. 잘못 가져왔으면 알림의 **[되돌리기]**.

공동편집용 양식(부서별 입력 탭 [엑셀 양식 만들기], 임원 [붙여넣기] ▾ → 공동편집용 엑셀 양식 만들기)도 이 모양입니다. 임원 양식에는 `맨 밑 표` 시트가 들어 있습니다.

# 부서별 일일 예정사항 (A4 한 장 자동 맞춤)

`일일예정사항.html`의 **부서별 일일 예정사항** 메뉴입니다. 파일 하나로 동작합니다.
인터넷, 설치, 공유폴더가 없어도 **더블클릭해서 Edge로 열면 됩니다**(Chrome·웨일도 됩니다).
외부 라이브러리나 웹폰트를 쓰지 않고, 어디로도 데이터를 보내지 않습니다(두 화면 모두 인터넷 요청 코드가 없음 — 일정 안에 넣은 링크는 사용자가 누를 때만 열림).
엑셀·한셀 파일은 직접 열지 않고(문서 보안), 한셀에서 복사한 내용을 붙여넣어 모읍니다.

## 매일 하는 일 — 한셀에서 붙여넣어 모으기

| 언제 | 무엇을 |
|---|---|
| 처음 한 번 | 부서마다 시트가 하나씩(시트 이름 = 부서명, A1 = `#부서명`) 있는 한셀 파일을 씁니다. 서식은 입력 탭의 **[엑셀 양식 만들기]**로 받을 수 있습니다. |
| 매일 (각 부서) | **자기 부서 시트에만** 씁니다. 2행 머리글 아래 한 줄에 일정 하나, `내용 / 날짜(괄호 안에 기입됨) / 비고(아스타로 표현) / 설명 / 링크(클릭하면 실행됨)` 칸에 나눠 씁니다. 시간은 내용 앞에(`09:00 주간회의`). |
| 매일 (취합) | 맨 마지막 **합본** 시트만 전체 선택·복사(위 **합본 시트**) → **[붙여넣기]** 창이나 화면에서 **Ctrl+V** → 확인 창 → **[가져오기]**. |
| 인쇄 | **[인쇄 / PDF]**. 화면으로 돌려 보게 하려면 저장 ▾ → 배포용 보기 파일. |

- 예시 파일: [`examples/일일예정_예시_13개부서.xlsx`](examples/일일예정_예시_13개부서.xlsx) — 13개 부서가 입력된 시트 모양 예시입니다(표가 들어간 부서 3곳 포함, 맨 끝 합본 시트를 복사해 붙여 보세요).
- 표를 넣으려면 일정 아래 **한 줄을 비우고**, A열부터 표 제목(한 칸, 선택) → 표 머리글 → 표 내용을 적습니다. 다음 빈 줄까지가 그 부서의 표가 됩니다.
- 부서는 **`#시트 이름` 줄**(양식의 각 시트 A1)로 찾습니다. 프로그램에 없는 부서도 머리글(내용…)이 있으면 새 부서로 추가됩니다. 한 시트에 모든 부서를 쓰려면 맨 앞에 `부서` 열을 두세요(병합된 칸도 됩니다).
- 괄호 없이 `날짜`라고만 쓴 열을 넣으면 문서 날짜에 맞는 줄만 가져옵니다(`날짜(괄호 안에 기입됨)` 열은 그냥 괄호 안에 인쇄). 받은 내용 대부분이 다른 날짜(예: 내일)이면 문서 날짜를 바꿀지 물어봅니다. 날짜 열이 없으면 시트 내용을 모두 가져오니 지난 일정은 지워 주세요.
- 아직 안 쓴 부서(머리글만 있는 시트), `# 작성방법` 같은 안내 시트는 알아서 뺍니다.
- 가져온 뒤 **입력 현황**(엑셀에서 / 직접 입력 / 비어 있음)과 아직 안 쓴 부서가 보입니다. [목록 복사]로 독촉 메시지를 만들 수 있고, 잘못 가져왔으면 알림의 **[되돌리기]**를 누르세요.

### 엑셀 칸 → 인쇄물

| 엑셀 | 인쇄물 |
|---|---|
| 내용 · 날짜(괄호 안에 기입됨) | 한 줄로: 예산안 제출 (11.14.) — 내용 앞의 `09:00`은 굵게 **09:00** |

| 내용 칸 안에서 `* ...`, 또는 내용이 `*`로 시작하는 줄 | **글씨 2pt 작은** 하위 항목 (`*`로 시작하는 줄은 바로 위 일정에 붙음) |
| 비고(아스타로 표현) (참석·대상·담당 등 다른 열도) | `*` 작은 글씨 하위 항목 |

| 이름이 정해진 것과 다른 표 | 표 그대로 |

- 엑셀에서 복사한 줄을 부서 입력칸에 붙여넣으면 `- 09:00 회의 @장소` 형태로 바뀌어 들어갑니다.

## A4 한 장 자동 맞춤

- 내용 양에 맞춰 글자크기·줄간격·자간·항목 간격을 함께 조절해 A4 한 장을 꽉 채웁니다(기본 7~13pt).
- 내용이 적으면 표를 페이지 아래 끝까지 늘리고, 그래도 넘치면 빨간 테두리와 넘친 길이(mm)를 보여 줍니다.
- **예정사항 좌우 2칸**(서식 탭, 기본 켜짐): 주요 예정사항 칸을 좌우 2칸으로 나누고, 일정(하위 항목·설명 포함)을 위에서부터 차례로 왼쪽 → 오른쪽에 높이가 비슷하도록 알아서 나눠 담습니다. 표는 제목과 함께 한 묶음으로 나눠 담습니다. 일정이 하나뿐이면 나누지 않고, 2단 레이아웃에서는 나누지 않습니다.
  - **표 배치**(서식 탭): 자동(열 5개 이상인 표만 넓게) / 모든 표 넓게 / 모든 표 칸 안에. **넓게** 둔 표는 일정은 좌우로 나눈 채 그 자리에서 두 칸에 걸쳐 들어갑니다.
  - 표마다 따로: 미리보기에서 표 오른쪽 위 **[↔ 넓게] / [칸에 담기]**를 누릅니다. 머리글이 같은 표는 다음 날 붙여넣어도 그대로입니다(알림의 [되돌리기]).
- 레이아웃은 표 / 표 2단 / 제목형 / 제목형 2단 중에서 고르고, A4 세로·가로, 하단 문구도 설정할 수 있습니다.

## 직접 입력할 때 (마크다운)

| 입력 | 결과 |
|---|---|
| `- 회의` | ○ 회의 |
| `  - 참석: 과장` (앞에 2칸) | 하위 항목(-) |
| `* 참석: 실장` (위 항목 아래) | 하위 항목, 글씨 2pt 작게 |
| `- 09:00 회의 @대회의실` | ○ **09:00** 회의 (대회의실) |
| `○`, `□`, `※`, `·` 직접 입력 | 입력한 기호 그대로 |
| `1.`, `가.`, `①` | 번호 그대로 |
| `**굵게**`, `__밑줄__`, `~~취소~~`, `[[형광펜]]`, `!!빨간 강조!!` | 글자 꾸밈 |
| `## 소제목`, `> 비고`, `---` | 소제목, 비고, 구분선 |
| 항목 바로 아래 `>> 설명` | 마우스를 올리면 나오는 설명 (인쇄 안 됨) |
| `[글자](주소)` 또는 항목 끝에 주소 | 누르면 열리는 링크 (주소는 인쇄 안 됨) |

- `Tab` / `Shift+Tab`: 들여쓰기 / 내어쓰기
- 목록 줄에서 `Enter`: 다음 기호가 자동으로 붙습니다. 빈 항목에서 한 번 더 누르면 목록이 끝납니다.
- **형광펜(마우스)**: 미리보기 위 **[형광펜]**을 누른 뒤 A4 위 글자를 마우스로 끌어 고르면 칠해지고, 칠한 곳을 다시 고르면 지워집니다(`Esc`로 끝). 글자를 먼저 고르고 눌러도 됩니다. 입력칸에서는 글자를 고르고 `Ctrl+Shift+H`(`Ctrl+Z`로 되돌리기). 목록 기호·시간·`@장소`는 칠하는 범위에서 빼고, 표는 칸마다, 링크는 통째로 감싸 깨지지 않습니다. 입력칸에는 `[[글자]]`로 보입니다(`==글==`은 이제 형광펜이 아님).
- **하위 줄 붙이기**(서식 탭 → 크기·간격, 기본 **가깝게**): 하위 항목(앞에 2칸 `-`, 작은 글씨 `*`)을 윗줄에 붙이는 정도를 **보통 / 가깝게 / 아주 가깝게** 중에서 고릅니다.
- **표 칸 폭**: 내용 안에 넣은 표는 미리보기에서 칸 사이 경계를 끌어 폭을 바꿉니다(편집 화면에서만, 마우스 옆에 mm 표시, `Alt`를 누르면 붙지 않음). 끄는 동안 글자크기는 그대로이고 놓으면 다시 맞춥니다. 경계를 누르고 `←` `→`로 0.5mm씩(`Shift`와 함께 5mm), 두 번 누르면 처음대로, 알림의 **[되돌리기]**. 폭은 **머리글이 같은 표**에 저장되어, 날이 바뀌어 다시 붙여넣어도 같은 폭으로 나옵니다.

## 저장

작업 내용을 파일(.json)로 저장하거나 불러오는 기능은 없습니다. 매일 한셀에서 복사해 **붙여넣기**로 넣어 씁니다.

- 작업 중인 내용은 이 브라우저에 **자동으로 남아** 새로고침하거나 다시 열어도 이어집니다(같은 비밀번호로 잠김). 브라우저 기록을 지우면 사라집니다.
- `Ctrl+S`를 눌러도 따로 저장하지 않고 안내만 나옵니다. 파일을 화면에 끌어다 놓아도 불러오지 않습니다.

| 저장 ▾ (부서별·임원 같음) | 용도 |
|---|---|
| 배포용 보기 파일(.html) | 받은 사람이 열면 보는 읽기 화면(고치는 칸 없음, 위쪽 [편집 화면 열기]로 고칠 수 있음). 저장한 **그 화면만** 위쪽 메뉴 없이 열립니다(다른 화면 내용은 들어 있지 않음). 내용이 파일 안에 같은 비밀번호로 잠겨 들어 있어, 다른 PC에서 껐다 켜도 그대로 보입니다. |
| 매일 쓸 양식 파일(.html) | 부서별: 부서 목록·서식만, 임원: 직위·성명·회사명·표 이름·서식만 담은 빈 양식. 어느 화면에서 저장해도 **두 화면의 양식이 함께** 든 `일일예정사항_양식.html` 하나가 나옵니다. 바탕화면에 두고 매일 이 파일을 여세요. |
| 비밀번호 바꾸기 | 아래 **비밀번호 · 암호화** 참고 |

- **비공개 여부**(두 화면): 미리보기 위 **[비공개 여부]**를 체크하면 A4 오른쪽 위에 빨간 `비공개` 상자가 붙고, 빼면 없어집니다. 부서별은 처음에 꺼짐, 임원은 처음에 켜짐. 문구는 서식 탭(부서별: 표시, 임원: 기타)에서 바꿉니다.

## 비밀번호 · 암호화 (두 화면 공통)

- `일일예정사항.html`은 **열 때마다 비밀번호**를 묻습니다(두 화면 함께 한 번). 처음 비밀번호는 **`1234`** 입니다. **받자마자 바꾸세요.**
- 파일 안의 화면·코드(예시 부서명·임원 이름 포함)는 **암호화**되어 있어(AES-256-GCM, 비밀번호로 키를 만듦: PBKDF2-SHA256 60만 번) 메모장으로 열어도 알아볼 수 없는 글자만 보입니다. 평문으로 보이는 것은 탭 제목, 비밀번호 입력 화면, 위쪽 메뉴 이름뿐입니다(두 화면의 꾸밈(CSS)도 암호화됨).
- 같은 비밀번호로 함께 잠기는 것: **브라우저 자동저장**, **배포용 보기 파일·양식 파일(.html)**. 받는 사람도 같은 비밀번호로 엽니다.
  - 다른 비밀번호로 잠긴 보기 파일이나 자동저장을 열면 그 비밀번호를 묻습니다.
  - 인쇄물·PDF·공동편집용 엑셀 양식(.xlsx)은 암호화되지 않습니다.
- **비밀번호는 어디에도 저장하지 않습니다**(브라우저 저장소에도 없음). 파일을 연 동안 메모리에만 있고 창을 닫으면 사라집니다.
- **비밀번호 바꾸기**: 두 화면 모두 위쪽 **저장 ▾ → 비밀번호 바꾸기**(임원은 서식 탭에도 있음). 어느 화면에서 바꿔도 두 화면이 함께 바뀝니다.
  - 새 비밀번호는 **8자 이상, 영문과 숫자를 함께** 넣어야 합니다.
  - 새 비밀번호로 다시 잠근 같은 이름의 파일을 내려받습니다. **지금 쓰는 파일을 이 파일로 바꾸고 옛 파일은 지우세요.** 옛 파일은 옛 비밀번호로 계속 열립니다.
  - 바꾼 뒤 그 창에서 저장하는 것(자동저장·보기·양식 파일)은 새 비밀번호로 잠깁니다.
- **비밀번호를 잊으면 풀 방법이 없습니다**(파일·자동저장 모두). 잘 보관하세요.
- Edge·Chrome·웨일에서 열어야 합니다(브라우저에 들어 있는 암호 기능을 씀).
- 개발용 평문 원본은 `src/`에 있습니다(`daily_schedule.html`·`executive_schedule.html`은 각자 열어 따로 시험할 수 있고, `shell.html`은 메뉴·잠금 틀). 배포 파일(루트의 `일일예정사항.html`)은 `node tools/seal.mjs`로 두 화면을 묶어 만듭니다(처음 비밀번호 `1234`, `node tools/seal.mjs 비밀번호`로 바꿀 수 있음).


- 입력 탭의 **배치** 그림에서 칸을 끌어다 다른 칸에 놓으면 두 임원의 자리가 바뀝니다(입력칸의 ▲▼도 됩니다).
- **칸 크기는 마우스로**: 미리보기에서 칸과 칸 사이 경계에 마우스를 올리면 파란 선이 보이고, 끌면 폭·높이가 바뀝니다. 마우스 옆에 바뀌는 크기(mm)가 나옵니다.
  - 좌우: 윗줄 칸 사이 2곳, 가운데 줄 큰 칸↔오른쪽, 아랫줄 칸 사이, **맨 밑 표**의 이름 칸 폭과 칸 사이(인접회사활동 5칸, 근무는 그때 칸 수 — 칸을 더하거나 빼면 근무 칸 폭은 똑같이로 돌아감)
  - 위아래: 줄과 줄 사이 2곳, 가운데 줄 오른쪽 위↔아래
  - 끄는 동안 글자크기는 그대로이고, 놓으면 다시 맞춥니다. 잘못 바꿨으면 알림의 **[되돌리기]**.
  - 다른 줄의 경계나 똑같이 나누는 자리에서 1.5mm 안이면 붙습니다. `Alt`를 누른 채 끌면 붙지 않습니다.
  - 경계를 **누르면 선택**되어(주황) 방향키로 0.5mm씩, `Shift`와 함께 5mm씩 움직입니다. **두 번 누르면** 그 경계만 처음대로 돌아갑니다.
  - 서식 탭 **칸 크기**에 지금 크기(mm)가 칸마다 나오고, 숫자를 직접 고쳐 쓰면 옆 칸이 그만큼 줄거나 늘어납니다. [가운데 큰 칸 2/3 / 1/2], [높이만 자동으로], [모두 처음대로]도 있습니다.
  - 높이를 직접 정하면 줄마다 그 높이 안에 들어가도록 글자크기를 맞춥니다.
- 서식 탭에서 A4 세로·가로, 여백, 글꼴, 글자크기 범위도 고릅니다.

## 한셀에서 붙여넣어 모으기

| 언제 | 무엇을 |
|---|---|
| 처음 한 번 | 임원마다 시트 하나(시트 이름 = 직위 성명, A1 = `#직위 성명`)와 `맨 밑 표` 시트(A1 = `#맨 밑 표`)가 있는 한셀 파일을 씁니다. 서식은 **[붙여넣기] ▾ → 공동편집용 엑셀 양식 만들기**로 받을 수 있습니다. |
| 매일 (각 비서) | 자기 임원 시트에 한 줄에 일정 하나: `시간 / 내용 / 비고 / ※ 참고`. 맨 밑 표는 `맨 밑 표` 시트에 `표 이름 / 칸 / 칸 제목 / 내용`. |
| 매일 (취합) | 맨 마지막 **합본** 시트만 전체 선택·복사(위 **합본 시트**) → **[붙여넣기]** 창이나 입력칸 밖에서 **Ctrl+V** → 확인 창 → **[가져오기]**. |

| 엑셀 칸 | 인쇄물 |
|---|---|
| 시간 · 내용 | **09:00** 내용 (엑셀 시간 형식 칸도 그대로 읽음) |
| 내용 끝 `@장소` 또는 `장소` 열 | 내용 (장소) |
| 내용 칸 안에서 줄 바꿈(Alt+Enter) 후 `* ...` / `- ...` | 작은 글씨 부가 설명 / 하위 항목 |
| 내용이 `*`로 시작하는 줄 | 바로 위 일정의 작은 글씨 부가 설명 |
| 비고 (참석 등 그 밖의 열은 `열이름: 값`) | 작은 글씨 부가 설명 `*` |
| ※ 참고 | 그 임원 칸 맨 밑 ※ |

- 임원은 **`#시트 이름` 줄(양식의 각 시트 A1)에 든 성명**으로 찾습니다(성명이 없으면 겹치지 않는 직위로). 못 찾으면 확인 창에서 고릅니다. 한 시트에 모두 쓰려면 `성명` 열을 두세요(병합된 칸도 됩니다).
- `# 맨 밑 표` 블록은 확인 창에 "맨 밑 표" 줄로 나오고, 체크하면 표 4개 중 붙인 표의 칸이 바뀝니다.
- `날짜` 열이 있으면 문서 날짜의 줄만 가져옵니다. 문서 날짜에 일정이 없으면 일정이 가장 많은 날짜를 골라 주고, 확인 창에서 바꿀 수 있습니다(가져오면 문서 날짜도 그 날짜로).
- 빈 시트(아직 안 쓴 임원), `# 작성방법` 시트는 뺍니다. 붙인 내용에 없는 임원은 그대로 둡니다. 잘못 가져왔으면 알림의 **[되돌리기]**.
- 예시 파일: [`examples/임원일일예정_예시_8명.xlsx`](examples/임원일일예정_예시_8명.xlsx) — 8명과 맨 밑 표가 입력된 시트 모양 예시입니다(맨 끝 합본 시트를 복사해 붙여 보세요).

## 입력 (임원마다 일정 칸 + ※ 칸)

| 일정 칸에 입력 | 인쇄물 |
|---|---|
| `09:00 주간 업무회의` | 시간 **09:00** / 내용 |
| `14:00~16:00 현장 점검` | 시간 범위 |
| `9:30`, `9시 반`, `오후 2시` | 09:30, 09:30, 14:00 으로 맞춤 |
| `종일 출장`, `오전 결재` | 시간 칸에 종일 / 오전 |
| `* 참석: 본부장 이상` | 바로 위 일정 밑에 **작은 글씨** 부가 설명 |
| `- 안건: ...` | 바로 위 일정 밑에 하위 항목 |
| `업무보고 @소회의실` | 업무보고 (소회의실) |
| `※ ...` | 그 임원 칸 맨 밑 참고 |

- **※ 칸**: 일정 칸 아래의 ※ 칸에 쓴 줄은 한 줄마다 ※가 붙어 그 임원 칸 **맨 밑**에 인쇄됩니다.
- **하위 줄 붙이기**(서식 탭 → 기타, 기본 **가깝게**): `*` 부가 설명과 `-` 하위 항목을 윗줄에 붙이는 정도를 **보통 / 가깝게 / 아주 가깝게** 중에서 고릅니다.
- 엑셀에서 `시간 / 내용 / 비고` 칸을 복사해 **한 임원의 일정 칸 안**에 붙여넣으면 그 임원 일정으로 한 줄씩 바뀌어 들어갑니다(비고 → `*` 부가 설명, 참고 → ※).
- 8칸 모두 같은 글자크기로 A4 한 장을 꽉 채우고, 남는 높이는 칸을 늘려 채웁니다. 넘치면 빨간 테두리와 넘친 길이(mm)를 보여 줍니다.
- 파일 저장·불러오기는 없습니다. 내용은 이 브라우저에 자동으로 남고(같은 비밀번호로 잠김), 매일 한셀에서 복사해 붙여넣습니다.

## 맨 밑 표 4개

- 입력 탭 맨 아래 **맨 밑 표**에 씁니다(배치 그림 아래 [맨 밑 표]를 누르거나 미리보기의 표를 눌러도 그 칸으로 갑니다).
- 인접회사활동은 회사 5곳(칸 제목에 회사명을 씀 — 처음에는 비어 있음), 휴가·출장/방문은 한 칸, 근무는 기본 2칸(칸 제목은 선택 — 비우면 제목 줄 없이)입니다. 표 이름도 고칠 수 있습니다.
- 칸마다 여러 줄을 쓸 수 있고, `10:00 회의`처럼 시간으로 시작하면 시간이 굵게, `* `로 시작하면 작은 글씨입니다.
- **근무는 칸 수와 칸 안의 줄을 그날그날 바꿉니다.**

  ```
  ┌────┬──────────────────┬──────────┬──────────┐
  │    │       당직        │ 비상대기  │ 상황근무  │  ← 칸 제목 (선택)
  │근무├──────────────────┼──────────┼──────────┤
  │    │ 주간 총무팀 과장   │ 비서실장  │ 1조 김민호│
  │    ├──────────────────┤          │          │  ← 당직 칸만 가로줄로 나눔 (줄 제목: 주간·야간)
  │    │ 야간 시설팀 대리   │          │          │
  └────┴──────────────────┴──────────┴──────────┘
  ```

  - **[+ 칸]**: 오른쪽 끝에 칸을 더합니다(8칸까지). 칸 오른쪽 위 **×**로 그 칸을 뺍니다.
  - **[줄 나누기]**: 그 칸 안을 가로줄로 나눠 줄을 하나 더 만듭니다(한 칸 6줄까지). 나누면 줄마다 **줄 제목** 칸이 생기고(주간·야간처럼, 비워도 됨), 인쇄물에서는 그 줄 앞에 굵게 찍힙니다. 줄 오른쪽 **×**로 그 줄을 빼면 다시 합쳐집니다.
  - 나누지 않은 칸은 옆 칸 높이에 맞춰 세로로 늘어납니다. 줄 수가 같은 칸끼리는 가로줄이 맞습니다.
  - 칸·줄을 빼면 알림의 **[되돌리기]**로 살릴 수 있습니다. **기본 2칸으로**를 누르면 칸 제목은 앞에서부터 그대로 두고 2칸·한 줄로 돌아갑니다(내용은 비움).
  - 한셀에서 붙여넣을 때는 `맨 밑 표` 시트에서 칸 번호를 늘리거나 같은 칸 번호를 한 번 더 씁니다(위 **합본 시트** 6번).
- 네 표는 왼쪽 이름 칸 폭이 같게 맞춰지고, 내용 높이만큼 차지합니다. 남는 높이는 위 임원 칸에 나눠 줍니다. 서식 탭에서 끌 수 있습니다.
- [새 문서]는 표 내용도 비웁니다(회사명·칸 제목·표 이름은 그대로). **근무는 기본 2칸·줄 나누기 없음으로 돌아갑니다**(칸 제목은 앞의 2칸 것을 그대로). 저장 ▾ → 매일 쓸 양식 파일도 근무는 기본 2칸으로 넣습니다.

## 형광펜

- 미리보기 위 **[형광펜]**을 누른 뒤 A4 위의 글자를 마우스로 끌어 고르면 노랗게 칠해집니다. 칠한 곳을 다시 고르면 지워집니다. 끝낼 때는 단추를 한 번 더 누르거나 `Esc`.
- 글자를 먼저 고르고 [형광펜]을 눌러도 됩니다.
- 입력칸에서는 글자를 고르고 `Ctrl+Shift+H`(다시 누르면 지움, `Ctrl+Z`로 되돌리기). 입력칸에는 `[[글자]]`로 보이며 직접 써도 됩니다. `==글자==`는 형광펜으로 읽지 않습니다(한셀에서 `=`는 수식).
- 시간·`*`·`@장소` 같은 기호는 칠하는 범위에서 알아서 빼서 일정 해석이 깨지지 않습니다. 인쇄에도 노랗게 나옵니다.

## 처음 한 번 (설치)

**`임원일일예정_대시보드.xlsm`을 쓰면** 1·2번은 건너뜁니다: 파일을 열고 노란 줄의 **[콘텐츠 사용]** → `Alt+F8` → **Setup** → [실행] → `Ctrl+S`.
빨간 줄 "Microsoft에서 이 파일의 매크로 실행을 차단했습니다"가 보이면 엑셀을 닫고, 탐색기에서 파일 오른쪽 단추 → **속성** → 아래쪽 **[차단 해제]** 체크 → 확인 뒤 다시 엽니다(인터넷에서 받은 파일이라 그렇습니다).
이 .xlsm은 엑셀에서 직접 저장한 것이 아니라 `tools/make_xlsm.py`로 만든 것입니다. 들어 있는 매크로는 `.bas`와 글자 하나까지 같은지 확인했지만, 엑셀에서 아직 열어 보지는 못했습니다. 열리지 않거나 매크로가 안 보이면 아래 1번부터 하세요.

1. 엑셀에서 **새 통합 문서**를 엽니다.
2. `Alt+F11` → **[파일] → [파일 가져오기]** → `임원일일예정_대시보드.bas`를 고릅니다.
3. 엑셀로 돌아와 `Alt+F8` → **Setup** → **[실행]**. 시트와 예시 일정 8명이 만들어지고 대시보드가 그려집니다.
4. **[다른 이름으로 저장]** → 파일 형식 **Excel 매크로 사용 통합 문서 (\*.xlsm)**.

- 다음부터는 저장한 .xlsm을 열고 노란 줄의 **[콘텐츠 사용]**을 누릅니다.
- 가져온 코드의 한글이 깨지면(Windows의 "UTF-8 사용" 설정을 켠 PC): VBA 편집기 **[삽입] → [모듈]**에 `_UTF8.txt` 내용을 모두 붙여넣고 3번부터 하면 됩니다.

3. **[인쇄 미리보기]**에서 인쇄하거나 **[PDF로 저장]**.

- 두레이로 모을 때: `설정` 시트의 **[공동편집 양식 만들기]**로 만든 .xlsx를 두레이에 올려 함께 쓰고, 내려받아 **[엑셀 불러오기]**. 시트 이름의 성명으로 임원을 찾고, `날짜` 열이 있으면 문서 날짜의 줄만(없으면 가장 많은 날짜를 물어봄), `성명` 열이 있으면 한 시트에 모두 써도 됩니다. 빈 시트·`작성방법` 시트는 뺍니다. 기존 예시 파일 [`examples/임원일일예정_예시_8명.xlsx`](examples/임원일일예정_예시_8명.xlsx)도 그대로 불러올 수 있습니다.
- 자리를 바꾸려면 `설정`의 배치 표에서 직위·성명을 바꿔 적으면 됩니다. 일정 시트는 성명으로 찾아 따라가고, 시트 이름도 "직위 성명"으로 맞춰집니다.
- **[일정 모두 비우기]**: 직위·성명·설정은 두고 임원별 시트의 일정만 지웁니다.

## A4 한 장 맞춤

- 8칸 모두 같은 글자크기로, `설정`의 최소~최대(기본 7~12pt) 안에서 한 장을 꽉 채우는 가장 큰 크기를 고릅니다. 남는 높이는 칸을 늘려 채우고, ※ 참고는 칸 맨 밑에 붙습니다.
- 용지(A4)·방향·여백·인쇄 영역·"한 페이지에 맞추기"는 매크로가 정해 둡니다. 인쇄 창의 설정은 그대로 두세요.
- 최소 글자크기로도 넘치면 대시보드 오른쪽에 빨간 글씨로 넘친 길이(mm)가 보이고, 인쇄는 한 장에 들어가게 조금 줄여서 찍힙니다.
- 칸 폭·높이는 `설정`의 **칸 크기 (비율)** 칸에서 바꿉니다(예: 가운데 줄 폭 `2 : 1` → `1 : 1`). 줄 높이·5번 칸 비율은 비워 두면 자동입니다.
- `대시보드` 시트는 새로 고침할 때마다 다시 그립니다. 손으로 고친 도형은 사라지니 내용은 임원별 시트에서 고치세요.

## 한셀용 (셀로만 그리는 판)

한셀은 글상자(도형) 매크로를 지원하지 않아 위 엑셀 판의 대시보드 그리기가 돌아가지 않습니다.
[`excel/임원일일예정_한셀.bas`](excel/임원일일예정_한셀.bas) (읽기·복사용 [`_UTF8.txt`](excel/임원일일예정_한셀_UTF8.txt))는 **셀 병합·테두리·행 높이만으로** 같은 8칸 배치를 그리는 짧은 판입니다(약 340줄, 엑셀에서도 돌아갑니다).

1. VBA 편집기에서 모듈을 하나 만들고 코드를 넣은 뒤 **Setup**을 한 번 실행합니다. `설정`·`입력`·`대시보드` 시트가 생깁니다.
2. `설정` 시트에 제목·날짜·자리 1~8의 직위·성명을, `입력` 시트에 일정을 씁니다: `자리(1~8) / 시간 / 내용 / 비고 / ※ 참고` (한 줄에 일정 하나, `@장소`, 내용 칸 안 `* ...`·`- ...`).
3. **MakeDashboard**를 실행하면 `대시보드` 시트에 A4 한 장 크기로 그립니다. 글자크기는 최대~최소 안에서 한 장에 들어가는 가장 큰 크기를 0.5pt 단위로 고릅니다.

- 글 높이는 글자 수로 어림합니다. 칸 아래쪽 글이 잘리면 `설정`의 **줄 높이 보정**(기본 1.7)을 1.8~2.0으로, 여백이 너무 남으면 1.5~1.6으로 바꿔 보세요.
- 한셀에서 매크로로 못 정한 인쇄 설정은 끝난 뒤 알림 창에 나옵니다. 그때는 인쇄의 쪽 설정에서 **A4 · 여백 · 한 쪽에 맞추기**를 직접 고르세요(한 번 정하면 파일에 남습니다).
- HTML·엑셀 판에 있는 시간 맞춤(`9시 반` → `09:30`), 글자 꾸밈(`**굵게**` 등), 두레이 파일 불러오기는 이 판에 없습니다.
- 한셀에서 `라이브러리가 등록되지 않았습니다`(-2147319779) 오류가 나는 경우가 있어, 변수를 `As Object` 대신 `As Worksheet`·`As Range`로 밝혀 쓰고 `Cells(행, 열)` 대신 `Range("A1")` 꼴로 씁니다(코드의 `★` 표시 줄).

[`hancell/임원일일예정_한셀.xlsm`](hancell/임원일일예정_한셀.xlsm)에는 아래 붙여넣기 모듈 7개가 이미 들어 있습니다(`tools/make_xlsm.py`로 만듦, CP949에 없는 글자 몇 개만 비슷한 글자로 바꿈).

(이 파일의 매크로는 LibreOffice에서 읽어 A4까지 만들어 보았지만, 한셀에서는 아직 열어 보지 못했습니다.)

## 처음 한 번 만들기 (15분)

한셀은 다른 프로그램이 넣어 둔 매크로를 읽지 않고, 매크로 가져오기 메뉴도 없어서 **매크로를 붙여넣어 한 번 만든 뒤 `.xlsm`으로 저장**합니다. 저장한 파일은 그다음부터 그대로 열어 씁니다.

붙여넣을 파일은 [`hancell/붙여넣기/임원/`](hancell/붙여넣기/임원/)의 `모듈1.txt` ~ `모듈7.txt` 입니다. 한셀이 큰 모듈을 읽지 못해서 작게 나눠 두었습니다. **번호 순서대로** 넣고, 하나 넣을 때마다 확인합니다.

1. 한셀에서 **새 문서**를 엽니다.
2. 매크로 편집기에서 **모듈을 하나** 만들고, `모듈1.txt` 내용 전체를 붙여넣습니다.
   - GitHub에서는 파일을 열고 **Raw** → Ctrl+A → Ctrl+C 하면 편합니다.
   - 붙여넣은 뒤 맨 아래 줄이 `' ==== 모듈 1 끝 ====` 인지 봅니다(잘리지 않고 다 들어갔는지).
3. **`Check1`** 을 실행합니다. "1번 모듈 확인" 창이 뜨면 다음으로 갑니다.
4. 새 모듈을 하나 더 만들어 `모듈2.txt` → `Check2`, … `모듈7.txt` → `Check7` 까지 같은 방법으로 넣습니다.
   - 확인 창이 안 뜨면 **거기서 멈추고 그 번호를 알려 주세요.** 그 모듈에 한셀이 못 읽는 것이 있다는 뜻입니다.
5. **`Setup`** 을 실행합니다. 입력·A4·임원 시트 8개·맨밑표·서식·입력방법 시트와 단추가 만들어지고, 예시 내용으로 A4가 한 번 그려집니다.
6. **다른 이름으로 저장 → `.xlsm`** 으로 저장합니다(예: `임원일일예정.xlsm`). 다시 열어도 모듈이 남아 있습니다.
7. 처음 열 때 매크로를 쓸지 물으면 사용을 고릅니다. 예시 내용은 [새 문서]로 비우세요.

> - 오류 창이 뜨면 창에 나온 **단계 이름**을 알려 주세요.
> - `Setup` 도중 한셀이 꺼지면, 저장해 둔 파일을 다시 열고 **`SetupStepByStep`** 을 실행하세요. 단계마다 창이 먼저 뜹니다. 꺼지기 직전에 본 단계 이름을 알려 주시면 됩니다. [A4 만들기]에서 꺼지면 `BuildA4StepByStep` 으로 같은 일을 합니다.

## 시험 상태

- 한셀 2020 에서 확인한 것: VBA 문법(`Dim … As Long`, `Mid$`, `IIf`, `Select Case`, `With`, `On Error GoTo`, `Optional`, `ReDim Preserve`, 2차원 배열, `GoTo` — [`hancell/한셀구문점검.txt`](hancell/한셀구문점검.txt)), 단추에 매크로 연결, `.xlsm`으로 저장 시 모듈 유지.

- 모든 단추는 붙여넣기 파일 7개 그대로 LibreOffice의 VBA 호환 기능에서 시험했습니다(Setup, A4 맞춤, 엑셀 불러오기, 붙여넣은 표, 되돌리기, 새 문서, 자리 바꾸기, 형광펜, 양식 만들기, 가로 용지, 칸 높이). 한셀에서 `Setup`까지 돌려 본 것은 아직입니다.
- 개발용: `hancell/src/`가 읽기 쉬운 원본, `python3 hancell/tools/build.py`가 `hancell/tools/hancellify.py`로 바꿔 `hancell/붙여넣기/임원/모듈N.txt`를 만들고 LibreOffice에서 시험합니다.
- 부서별 화면의 한셀 판은 아직 만드는 중입니다.
