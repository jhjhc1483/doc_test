# 부서별 일일 예정사항 (A4 한 장 자동 맞춤)

`daily_schedule.html` 파일 하나로 동작합니다.
인터넷, 설치, 파이썬이 없어도 **더블클릭해서 브라우저로 열면 됩니다**(Chrome·Edge·웨일 등).
외부 라이브러리나 웹폰트는 쓰지 않습니다.

## 하는 일

1. 부서마다 예정사항을 마크다운(줄글)으로 입력합니다.
2. 오른쪽 A4 미리보기에 바로 반영됩니다.
3. **자동 맞춤**: 내용 양에 맞춰 글자크기·줄간격·자간·항목 간격을 함께 조절해 A4 한 장을 꽉 채웁니다.
   - 내용이 적으면 최대 글자크기(기본 13pt)까지 키우고, 표를 페이지 아래 끝까지 늘립니다.
   - 내용이 많으면 최소 글자크기(기본 7pt)까지 줄입니다. 그래도 넘치면 빨간 테두리와 넘친 길이(mm)를 보여 줍니다.
4. [인쇄 / PDF]로 인쇄하거나 PDF로 저장합니다.

## 입력 방법

| 입력 | 결과 |
|---|---|
| `- 회의` | ○ 회의 |
| `  - 참석: 과장` (앞에 2칸) | 하위 항목(-) |
| `○`, `□`, `※`, `·` 직접 입력 | 입력한 기호 그대로 |
| `1.`, `가.`, `①` | 번호 그대로 |
| `09:00 회의` | 줄 앞 시간 자동 굵게 |
| `**굵게**`, `__밑줄__`, `~~취소~~`, `==형광펜==`, `!!빨간 강조!!` | 글자 꾸밈 |
| `## 소제목`, `> 비고`, `---` | 소제목, 비고, 구분선 |
| 세로줄로 칸을 나눈 줄 (아래 예시) | 표 |

```
| 시간 | 내용 | 장소 |
|---|---|---|
| 10:00 | 계약심의 | 소회의실 |
```

- `Tab` / `Shift+Tab`: 들여쓰기 / 내어쓰기
- 목록 줄에서 `Enter`: 다음 기호가 자동으로 붙습니다. 빈 항목에서 한 번 더 누르면 목록이 끝납니다.

## 레이아웃 (서식 탭)

- **표**: 부서 | 주요 예정사항 (기본값)
- **표 2단**: 표를 좌우 두 단으로 나눕니다. 부서가 많고 내용이 짧을 때 글자를 더 크게 쓸 수 있습니다.
- **제목형 / 제목형 2단**: 부서명을 제목으로 두고 내용을 아래에 씁니다.
- A4 세로·가로, 여백, 글꼴(맑은 고딕, 나눔고딕, 함초롬 등 PC에 설치된 글꼴), 결재란, 하단 문구를 설정할 수 있습니다.

## 저장 (재부팅해도 남기려면)

브라우저 자동저장은 **새로고침 대비용**입니다. 재부팅하면 사라지므로 파일로 남기세요.

| 메뉴 | 용도 |
|---|---|
| 저장 (`Ctrl+S`) | `.json` 데이터 파일. [불러오기]로 그대로 이어서 작업합니다. |
| 텍스트(.txt)로 내보내기 | `# 부서명`으로 구분된 텍스트. 메신저나 메일로 보낼 때 씁니다. |
| HTML 사본 저장 (내용 포함) | 열면 지금 화면 그대로 보이는 HTML 파일 |
| HTML 양식 저장 (부서 목록·서식만) | **매일 쓰는 기본 양식.** 이 파일을 열면 부서·서식이 갖춰진 빈 문서가 오늘 날짜로 열립니다. |

> 화면 위쪽에 `● 파일로 저장 안 됨`이 보이면 아직 파일로 저장하지 않은 상태입니다.

## 여러 부서 내용 한 번에 받기

- **파일로 받기**: 부서마다 메모장으로 `부서명.txt`를 만들어 공유폴더에 둡니다(`2026-11-09_기획과.txt`처럼 날짜가 붙어도 됩니다).
  취합하는 사람이 [불러오기]에서 여러 파일을 한꺼번에 고르거나 화면에 끌어다 놓으면, 파일 이름으로 부서를 찾아 내용을 넣습니다.
  UTF-8 파일과 예전 메모장(ANSI/EUC-KR) 파일을 모두 읽습니다.
- **붙여넣기**: [일괄 붙여넣기]에 부서마다 `# 부서명` 줄로 구분해 넣습니다. 이미 있는 부서는 `[부서명]`으로 써도 됩니다.

```
# 기획과
- 10:00 주간회의

# 총무과
- 14:00 소방점검
```

## 인쇄 팁

- 인쇄 창에서 용지 **A4**, 배율 **기본값(100%)**, 여백 **기본값**으로 두세요.
- 미리보기에서 부서를 클릭하면 그 부서의 입력칸으로 이동합니다.
