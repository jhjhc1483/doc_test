# 부서별 일일 예정사항 (A4 한 장 자동 맞춤)

`daily_schedule.html` 파일 하나로 동작합니다.
인터넷, 설치, 공유폴더가 없어도 **더블클릭해서 Edge로 열면 됩니다**(Chrome·웨일도 됩니다).
외부 라이브러리나 웹폰트를 쓰지 않고, 어디로도 데이터를 보내지 않습니다.
엑셀(.xlsx) 읽기·쓰기도 이 파일 안에서 직접 처리합니다.

## 매일 하는 일 — 엑셀(두레이 공동편집)로 모으기

| 언제 | 무엇을 |
|---|---|
| 처음 한 번 | 입력 탭의 **[엑셀 양식 만들기]**를 누릅니다. 부서마다 시트가 하나씩 있는 `일일예정_공동편집양식.xlsx`가 만들어집니다. 이 파일을 두레이에 올려 공동편집으로 엽니다. (부서가 바뀌면 다시 만드세요.) |
| 매일 (각 부서) | **자기 부서 시트에만** 씁니다. 한 줄에 일정 하나, `시간 / 내용 / 장소 / 비고 / 설명 / 링크` 칸에 나눠 씁니다. |
| 매일 (취합) | 두레이에서 파일을 내려받아 **[엑셀 불러오기]**로 고르고(화면에 끌어다 놓아도 됨), 확인 창에서 **[가져오기]**를 누릅니다. 또는 두레이(엑셀)에서 범위를 복사해 프로그램 화면에서 **Ctrl+V** 합니다. |
| 인쇄 | **[인쇄 / PDF]**. 화면으로 돌려 보게 하려면 저장 ▾ → 배포용 보기 파일. |

- 예시 파일: [`examples/일일예정_예시_13개부서.xlsx`](examples/일일예정_예시_13개부서.xlsx) — 13개 부서가 입력된 공동편집 양식입니다(표가 들어간 부서 3곳 포함). [엑셀 불러오기]로 올려 보면 어떻게 들어가는지 볼 수 있습니다.
- 표를 넣으려면 일정 아래 **한 줄을 비우고**, A열부터 표 제목(한 칸, 선택) → 표 머리글 → 표 내용을 적습니다. 다음 빈 줄까지가 그 부서의 표가 됩니다.
- 부서는 **시트 이름**으로 찾습니다. 프로그램에 없는 부서 시트도 머리글(시간·내용…)이 있으면 새 부서로 추가됩니다(`Sheet1` 같은 기본 이름은 제외). 한 시트에 모든 부서를 쓰려면 맨 앞에 `부서` 열을 두세요(병합된 칸도 됩니다).
- `날짜` 열을 넣으면 문서 날짜에 맞는 줄만 가져옵니다. 받은 내용 대부분이 다른 날짜(예: 내일)이면 문서 날짜를 바꿀지 물어봅니다. 날짜 열이 없으면 시트 내용을 모두 가져오니 지난 일정은 지워 주세요.
- 아직 안 쓴 부서 시트(빈 시트), `작성방법` 같은 안내 시트, 숨긴 시트는 알아서 뺍니다.
- 가져온 뒤 **입력 현황**(엑셀에서 / 직접 입력 / 비어 있음)과 아직 안 쓴 부서가 보입니다. [목록 복사]로 독촉 메시지를 만들 수 있고, 잘못 가져왔으면 알림의 **[되돌리기]**를 누르세요.

### 엑셀 칸 → 인쇄물

| 엑셀 | 인쇄물 |
|---|---|
| 시간 · 내용 · 장소 | 한 줄로: **09:00** 주간회의 (대회의실) |
| 내용 칸 안에서 줄 바꿈(Alt+Enter) 후 `- ...` | 하위 항목 |
| 내용 칸 안에서 `* ...`, 또는 내용이 `*`로 시작하는 줄 | **글씨 2pt 작은** 하위 항목 (`*`로 시작하는 줄은 바로 위 일정에 붙음) |
| 비고 (참석·대상·담당 등 다른 열도) | 작은 글씨 하위 항목 |
| 설명 | 화면에서 마우스를 올리면 나오는 팝업 (인쇄 안 됨) |
| 링크 | 누르면 열리는 링크 (주소는 인쇄 안 됨) |
| 이름이 정해진 것과 다른 표 | 표 그대로 |

- 읽는 형식: **.xlsx** (엑셀에서 **.xml**("XML 스프레드시트 2003")·**.csv**로 저장한 것도 됩니다). 예전 엑셀(.xls)은 .xlsx로 저장해서 올려 주세요.
- 엑셀에서 복사한 줄을 부서 입력칸에 붙여넣으면 `- 09:00 회의 @장소` 형태로 바뀌어 들어갑니다.

## A4 한 장 자동 맞춤

- 내용 양에 맞춰 글자크기·줄간격·자간·항목 간격을 함께 조절해 A4 한 장을 꽉 채웁니다(기본 7~13pt).
- 내용이 적으면 표를 페이지 아래 끝까지 늘리고, 그래도 넘치면 빨간 테두리와 넘친 길이(mm)를 보여 줍니다.
- **예정사항 좌우 2칸**(서식 탭, 기본 켜짐): 주요 예정사항 칸을 좌우 2칸으로 나누고, 일정(하위 항목·설명 포함)을 위에서부터 차례로 왼쪽 → 오른쪽에 높이가 비슷하도록 알아서 나눠 담습니다. 표는 제목과 함께 한 묶음으로 나눠 담습니다. 일정이 하나뿐이거나 넓은 표(열 5개 이상)가 있는 부서는 두 칸을 합쳐 쓰고, 2단 레이아웃에서는 나누지 않습니다.
- 레이아웃은 표 / 표 2단 / 제목형 / 제목형 2단 중에서 고르고, A4 세로·가로, 결재란, 하단 문구도 설정할 수 있습니다.

## 직접 입력할 때 (마크다운)

| 입력 | 결과 |
|---|---|
| `- 회의` | ○ 회의 |
| `  - 참석: 과장` (앞에 2칸) | 하위 항목(-) |
| `* 참석: 실장` (위 항목 아래) | 하위 항목, 글씨 2pt 작게 |
| `- 09:00 회의 @대회의실` | ○ **09:00** 회의 (대회의실) |
| `○`, `□`, `※`, `·` 직접 입력 | 입력한 기호 그대로 |
| `1.`, `가.`, `①` | 번호 그대로 |
| `**굵게**`, `__밑줄__`, `~~취소~~`, `==형광펜==`, `!!빨간 강조!!` | 글자 꾸밈 |
| `## 소제목`, `> 비고`, `---` | 소제목, 비고, 구분선 |
| 항목 바로 아래 `>> 설명` | 마우스를 올리면 나오는 설명 (인쇄 안 됨) |
| `[글자](주소)` 또는 항목 끝에 주소 | 누르면 열리는 링크 (주소는 인쇄 안 됨) |

- `Tab` / `Shift+Tab`: 들여쓰기 / 내어쓰기
- 목록 줄에서 `Enter`: 다음 기호가 자동으로 붙습니다. 빈 항목에서 한 번 더 누르면 목록이 끝납니다.

## 저장 (재부팅해도 남기려면)

브라우저 자동저장은 **새로고침 대비용**입니다. 재부팅하면 사라지므로 파일로 남기세요.

| 메뉴 | 용도 |
|---|---|
| 저장 (`Ctrl+S`) | 작업 파일(.json). [엑셀 불러오기] ▾ → 저장해 둔 작업 열기로 이어서 작업합니다. |
| 배포용 보기 파일(.html) | 받은 사람이 열면 링크·설명 팝업이 되는 읽기 화면 |
| 매일 쓸 양식 파일(.html) | 부서 목록·서식만 담은 빈 양식. 바탕화면에 두고 매일 이 파일을 여세요. |

> 화면 위쪽에 `● 파일로 저장 안 됨`이 보이면 아직 파일로 저장하지 않은 상태입니다.

## 인쇄 팁

- 인쇄 창에서 용지 **A4**, 배율 **기본값(100%)**, 여백 **기본값**으로 두세요. 'PDF로 저장'한 파일에서도 링크는 눌립니다.
- 미리보기에서 부서를 클릭하면 그 부서의 입력칸으로 이동합니다.

# 임원 일일 예정사항 (8명 · A4 한 장)

`executive_schedule.html` — 임원 8명의 하루 일정을 정해진 자리에 넣어 A4 한 장으로 뽑습니다.
`daily_schedule.html`과 같이 파일 하나로, 설치·인터넷 없이 더블클릭해서 엽니다.

## 배치

```
┌──────┬──────┬──────┐
│  1   │  2   │  3   │   윗줄 3명
├──────┴──────┼──────┤
│             │  5   │
│      4      ├──────┤   가운데 줄: 왼쪽 큰 칸 1명, 오른쪽 위·아래 2명
│   (큰 칸)    │  6   │
├─────────┬───┴──────┤
│    7    │    8     │   아랫줄 2명
└─────────┴──────────┘
```

- 입력 탭의 **배치** 그림에서 칸을 끌어다 다른 칸에 놓으면 두 임원의 자리가 바뀝니다(입력칸의 ▲▼도 됩니다).
- **칸 크기는 마우스로**: 미리보기에서 칸과 칸 사이 경계에 마우스를 올리면 파란 선이 보이고, 끌면 폭·높이가 바뀝니다.
  - 좌우: 윗줄 칸 사이 2곳, 가운데 줄 큰 칸↔오른쪽, 아랫줄 칸 사이
  - 위아래: 줄과 줄 사이 2곳, 가운데 줄 오른쪽 위↔아래
  - 다른 줄의 경계나 똑같이 나누는 자리에서 살짝 붙습니다. 경계를 **두 번 누르면** 그 경계만 처음대로 돌아갑니다.
  - 높이를 직접 정하면 줄마다 그 높이 안에 들어가도록 글자크기를 맞춥니다. 서식 탭에 지금 크기(mm)와 [가운데 큰 칸 2/3 / 1/2], [높이만 자동으로], [모두 처음대로]가 있습니다.
- 서식 탭에서 A4 세로·가로, 여백, 글꼴, 글자크기 범위도 고릅니다.

## 엑셀(두레이 공동편집)로 모으기

| 언제 | 무엇을 |
|---|---|
| 처음 한 번 | **엑셀 불러오기 ▾ → 공동편집용 엑셀 양식 만들기**. `작성방법` 시트와 임원마다 시트 하나(시트 이름 = 직위 성명)가 든 `임원일일예정_공동편집양식.xlsx`가 만들어집니다. 두레이에 올려 함께 씁니다. |
| 매일 (각 비서) | 자기 임원 시트에 한 줄에 일정 하나: `시간 / 내용 / 비고 / ※ 참고` |
| 매일 (취합) | 파일을 내려받아 **[엑셀 불러오기]**로 고르거나 화면에 끌어다 놓고, 확인 창에서 **[가져오기]**. 범위를 복사해 입력칸 밖에서 **Ctrl+V** 해도 됩니다. |

| 엑셀 칸 | 인쇄물 |
|---|---|
| 시간 · 내용 | **09:00** 내용 (엑셀 시간 형식 칸도 그대로 읽음) |
| 내용 끝 `@장소` 또는 `장소` 열 | 내용 (장소) |
| 내용 칸 안에서 줄 바꿈(Alt+Enter) 후 `* ...` / `- ...` | 작은 글씨 부가 설명 / 하위 항목 |
| 내용이 `*`로 시작하는 줄 | 바로 위 일정의 작은 글씨 부가 설명 |
| 비고 (참석 등 그 밖의 열은 `열이름: 값`) | 작은 글씨 부가 설명 `*` |
| ※ 참고 | 그 임원 칸 맨 밑 ※ |

- 임원은 **시트 이름에 든 성명**으로 찾습니다(성명이 없으면 겹치지 않는 직위로). 못 찾으면 확인 창에서 고릅니다. 한 시트에 모두 쓰려면 `성명` 열을 두세요(병합된 칸도 됩니다).
- `날짜` 열이 있으면 문서 날짜의 줄만 가져옵니다. 문서 날짜에 일정이 없으면 일정이 가장 많은 날짜를 골라 주고, 확인 창에서 바꿀 수 있습니다(가져오면 문서 날짜도 그 날짜로).
- 빈 시트(아직 안 쓴 임원), `작성방법` 시트, 숨긴 시트는 뺍니다. 엑셀에 없는 임원은 그대로 둡니다. 잘못 가져왔으면 알림의 **[되돌리기]**.
- 예시 파일: [`examples/임원일일예정_예시_8명.xlsx`](examples/임원일일예정_예시_8명.xlsx) — 8명이 입력된 공동편집 양식입니다.
- 읽는 형식: **.xlsx** (엑셀에서 **.csv**로 저장한 것도 됩니다). 예전 엑셀(.xls)은 .xlsx로 저장해서 올려 주세요.

## 입력 (임원마다 일정 칸 + ※ 칸)

| 일정 칸에 입력 | 인쇄물 |
|---|---|
| `09:00 주간 업무회의` | 시간 **09:00** / 내용 |
| `14:00~16:00 현장 점검` | 시간 범위 |
| `9:30`, `9시 반`, `오후 2시` | 09:30, 09:30, 14:00 으로 맞춤 |
| `종일 출장`, `오전 결재` | 시간 칸에 종일 / 오전 |
| `* 참석: 본부장 이상` | 바로 위 일정 밑에 **작은 글씨** 부가 설명 |
| `- 안건: ...` | 바로 위 일정 밑에 하위 항목 |
| `업무보고 @소회의실` | 업무보고 (소회의실) |
| `※ ...` | 그 임원 칸 맨 밑 참고 |

- **※ 칸**: 일정 칸 아래의 ※ 칸에 쓴 줄은 한 줄마다 ※가 붙어 그 임원 칸 **맨 밑**에 인쇄됩니다.
- 엑셀에서 `시간 / 내용 / 비고` 칸을 복사해 **한 임원의 일정 칸 안**에 붙여넣으면 그 임원 일정으로 한 줄씩 바뀌어 들어갑니다(비고 → `*` 부가 설명, 참고 → ※).
- 8칸 모두 같은 글자크기로 A4 한 장을 꽉 채우고, 남는 높이는 칸을 늘려 채웁니다. 넘치면 빨간 테두리와 넘친 길이(mm)를 보여 줍니다.
- 저장(`Ctrl+S`)은 작업 파일(.json)입니다. **엑셀 불러오기 ▾ → 저장해 둔 작업(.json) 열기** 또는 화면에 끌어다 놓아 다시 엽니다.

# 임원 일일 예정사항 — 엑셀(VBA) 대시보드

`executive_schedule.html`과 같은 8칸 배치·입력 규칙을 **엑셀 매크로**로 옮긴 판입니다.
`대시보드` 시트에 A4 한 장이 그대로 그려지고, 인쇄·PDF는 늘 **A4 한 장**으로 나옵니다.

| 파일 | 쓰임 |
|---|---|
| [`excel/임원일일예정_대시보드.bas`](excel/임원일일예정_대시보드.bas) | VBA 편집기 [파일 가져오기]로 넣는 파일 (Windows 한글 인코딩) |
| [`excel/임원일일예정_대시보드_UTF8.txt`](excel/임원일일예정_대시보드_UTF8.txt) | 같은 코드의 읽기·복사용 사본 |

## 처음 한 번 (설치)

1. 엑셀에서 **새 통합 문서**를 엽니다.
2. `Alt+F11` → **[파일] → [파일 가져오기]** → `임원일일예정_대시보드.bas`를 고릅니다.
3. 엑셀로 돌아와 `Alt+F8` → **Setup** → **[실행]**. 시트와 예시 일정 8명이 만들어지고 대시보드가 그려집니다.
4. **[다른 이름으로 저장]** → 파일 형식 **Excel 매크로 사용 통합 문서 (\*.xlsm)**.

- 다음부터는 저장한 .xlsm을 열고 노란 줄의 **[콘텐츠 사용]**을 누릅니다.
- 가져온 코드의 한글이 깨지면(Windows의 "UTF-8 사용" 설정을 켠 PC): VBA 편집기 **[삽입] → [모듈]**에 `_UTF8.txt` 내용을 모두 붙여넣고 3번부터 하면 됩니다.

## 시트

| 시트 | 내용 |
|---|---|
| `대시보드` | A4 한 장 화면. 오른쪽에 [새로 고침] [인쇄 미리보기] [PDF로 저장] [엑셀 불러오기] 단추와 결과(글자크기·넘침)가 보입니다(단추는 인쇄되지 않음). |
| `설정` | 제목·날짜·왼쪽 위 문구·하단 문구, 자리 1~8의 직위·성명(배치 그림이 같이 바뀜), 용지 방향·여백·글꼴·글자크기 범위, 칸 크기 비율 |
| 임원별 시트 (시트 이름 = 직위 성명) | 한 줄에 일정 하나: `시간 / 내용 / 비고 / ※ 참고` — 두레이 공동편집 양식과 같은 모양 |

## 매일

1. 임원별 시트에 일정을 씁니다(입력 규칙은 위 HTML 판과 같습니다: `09:00`·`9시 반`·`오후 2시`·`종일`, `@장소`, 내용 칸 안 `* 부가 설명` / `- 하위 항목`, `**굵게**` `!!빨간 강조!!` 등).
2. **[새로 고침]** 또는 `Ctrl+Shift+R`.
3. **[인쇄 미리보기]**에서 인쇄하거나 **[PDF로 저장]**.

- 두레이로 모을 때: `설정` 시트의 **[공동편집 양식 만들기]**로 만든 .xlsx를 두레이에 올려 함께 쓰고, 내려받아 **[엑셀 불러오기]**. 시트 이름의 성명으로 임원을 찾고, `날짜` 열이 있으면 문서 날짜의 줄만(없으면 가장 많은 날짜를 물어봄), `성명` 열이 있으면 한 시트에 모두 써도 됩니다. 빈 시트·`작성방법` 시트는 뺍니다. 기존 예시 파일 [`examples/임원일일예정_예시_8명.xlsx`](examples/임원일일예정_예시_8명.xlsx)도 그대로 불러올 수 있습니다.
- 자리를 바꾸려면 `설정`의 배치 표에서 직위·성명을 바꿔 적으면 됩니다. 일정 시트는 성명으로 찾아 따라가고, 시트 이름도 "직위 성명"으로 맞춰집니다.
- **[일정 모두 비우기]**: 직위·성명·설정은 두고 임원별 시트의 일정만 지웁니다.

## A4 한 장 맞춤

- 8칸 모두 같은 글자크기로, `설정`의 최소~최대(기본 7~12pt) 안에서 한 장을 꽉 채우는 가장 큰 크기를 고릅니다. 남는 높이는 칸을 늘려 채우고, ※ 참고는 칸 맨 밑에 붙습니다.
- 용지(A4)·방향·여백·인쇄 영역·"한 페이지에 맞추기"는 매크로가 정해 둡니다. 인쇄 창의 설정은 그대로 두세요.
- 최소 글자크기로도 넘치면 대시보드 오른쪽에 빨간 글씨로 넘친 길이(mm)가 보이고, 인쇄는 한 장에 들어가게 조금 줄여서 찍힙니다.
- 칸 폭·높이는 `설정`의 **칸 크기 (비율)** 칸에서 바꿉니다(예: 가운데 줄 폭 `2 : 1` → `1 : 1`). 줄 높이·5번 칸 비율은 비워 두면 자동입니다.
- `대시보드` 시트는 새로 고침할 때마다 다시 그립니다. 손으로 고친 도형은 사라지니 내용은 임원별 시트에서 고치세요.

## 한셀용 (셀로만 그리는 판)

한셀은 글상자(도형) 매크로를 지원하지 않아 위 엑셀 판의 대시보드 그리기가 돌아가지 않습니다.
[`excel/임원일일예정_한셀.bas`](excel/임원일일예정_한셀.bas) (읽기·복사용 [`_UTF8.txt`](excel/임원일일예정_한셀_UTF8.txt))는 **셀 병합·테두리·행 높이만으로** 같은 8칸 배치를 그리는 짧은 판입니다(약 340줄, 엑셀에서도 돌아갑니다).

1. VBA 편집기에서 모듈을 하나 만들고 코드를 넣은 뒤 **Setup**을 한 번 실행합니다. `설정`·`입력`·`대시보드` 시트가 생깁니다.
2. `설정` 시트에 제목·날짜·자리 1~8의 직위·성명을, `입력` 시트에 일정을 씁니다: `자리(1~8) / 시간 / 내용 / 비고 / ※ 참고` (한 줄에 일정 하나, `@장소`, 내용 칸 안 `* ...`·`- ...`).
3. **MakeDashboard**를 실행하면 `대시보드` 시트에 A4 한 장 크기로 그립니다. 글자크기는 최대~최소 안에서 한 장에 들어가는 가장 큰 크기를 0.5pt 단위로 고릅니다.

- 글 높이는 글자 수로 어림합니다. 칸 아래쪽 글이 잘리면 `설정`의 **줄 높이 보정**(기본 1.7)을 1.8~2.0으로, 여백이 너무 남으면 1.5~1.6으로 바꿔 보세요.
- 한셀에서 매크로로 못 정한 인쇄 설정은 끝난 뒤 알림 창에 나옵니다. 그때는 인쇄의 쪽 설정에서 **A4 · 여백 · 한 쪽에 맞추기**를 직접 고르세요(한 번 정하면 파일에 남습니다).
- HTML·엑셀 판에 있는 시간 맞춤(`9시 반` → `09:30`), 글자 꾸밈(`**굵게**` 등), 두레이 파일 불러오기는 이 판에 없습니다.
- 한셀에서 `라이브러리가 등록되지 않았습니다`(-2147319779) 오류가 나는 경우가 있어, 변수를 `As Object` 대신 `As Worksheet`·`As Range`로 밝혀 쓰고 `Cells(행, 열)` 대신 `Range("A1")` 꼴로 씁니다(코드의 `★` 표시 줄).
