엑셀로 모으기 (두레이 공동편집)

  1. 처음 한 번: 입력 탭의 [엑셀 양식 만들기]를 누릅니다. 부서마다 시트가 하나씩 있는 일일예정_공동편집양식.xlsx가 만들어집니다. 이 파일을 두레이에 올려 공동편집으로 엽니다. (부서가 바뀌면 다시 만드세요.)
  2. 매일 (각 부서): 자기 부서 시트에만 씁니다. 한 줄에 일정 하나, 시간 / 내용 / 장소 / 비고 / 설명 / 링크 칸에 나눠 씁니다.
  3. 취합: 두레이에서 파일을 내려받아 [엑셀 불러오기]로 고르고, 확인 창에서 [가져오기]. 또는 두레이(엑셀)에서 범위를 복사해 이 화면에서 Ctrl+V.
  4. 인쇄: [인쇄 / PDF]. 화면으로 돌려 보게 하려면 저장 ▾ → 배포용 보기 파일.

링크·설명 팝업 (화면에서만, 인쇄 안 됨)

입력화면에서
[회의자료](http://주소)‘회의자료’를 누르면 링크가 열립니다. 인쇄물에는 글자만 나옵니다.
- 10:00 주간회의 http://주소항목 전체가 링크가 됩니다. 주소는 인쇄되지 않습니다.
항목 바로 아래 줄에
>> 안건: 예산안, 인사		그 항목에 마우스를 올리면 설명 팝업이 나옵니다.
부서 내용 맨 위에 >> 담당: 홍길동(1234)부서명에 마우스를 올리면 나옵니다.

엑셀에서는 설명·링크 칸에 쓰면 됩니다. 화면의 점선 밑줄은 설명이 있는 항목, 파란 글자는 링크입니다. ‘PDF로 저장’한 파일에서도 링크는 눌립니다.

입력 팁

  • Tab 들여쓰기, Shift+Tab 내어쓰기 (여러 줄을 선택해도 됩니다)
  • 목록 줄에서 Enter를 누르면 다음 기호가 자동으로 붙고, 빈 항목에서 한 번 더 누르면 목록이 끝납니다.
  • 엑셀에서 복사한 줄을 부서 입력칸에 붙여넣으면 - 시간 내용 @장소 형태로 바뀌어 들어갑니다.
  • 미리보기에서 부서를 클릭하면 그 부서의 입력칸으로 이동합니다.

저장 (재부팅해도 남기려면)

  • 브라우저 자동저장은 새로고침에만 대비합니다. 재부팅하면 사라지니 [저장]으로 파일을 남기세요.
  • 매일 같은 부서·서식으로 시작하려면 저장 ▾ → 매일 쓸 양식 파일을 바탕화면에 두고 그 파일을 여세요.
  • 완성본을 화면으로 돌려 보게 하려면 저장 ▾ → 배포용 보기 파일을 보내세요. 링크와 설명 팝업이 동작합니다.

인쇄

  • 인쇄 창에서 용지 A4, 배율 기본값(100%), 여백 기본값으로 두세요. ‘PDF로 저장’도 됩니다.
  • 빨간 테두리가 보이면 한 장을 넘는 상태입니다. 서식 탭에서 최소 글자크기를 낮추거나 2단·가로로 바꿔 보세요.

엑셀에서 복사한 내용 붙여넣기

엑셀(두레이)에서 범위를 복사(Ctrl+C)해 아래에 붙여넣으세요. 머리글 줄(시간·내용·장소…)까지 같이 복사하면 더 정확합니다. 부서 열이 있으면 부서별로 나눠 넣고, 없으면(한 부서 시트만 복사했으면) 확인 창에서 부서를 고릅니다.
