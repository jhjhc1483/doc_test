한셀(엑셀)에서 붙여넣어 모으기

  1. 처음 한 번: 부서마다 시트가 하나씩(시트 이름 = 부서명) 있는 한셀 파일을 씁니다. 서식은 입력 탭의 [엑셀 양식 만들기]로 받을 수 있습니다.
  2. 매일 (각 부서): 자기 부서 시트에만 씁니다. 한 줄에 일정 하나, 내용 / 날짜(괄호 안에 기입됨) / 비고(아스타로 표현) / 설명 / 링크(클릭하면 실행됨) 칸에 나눠 씁니다. 시트 맨 위 A1에는 #부서명이 있습니다(양식에 들어 있음).
  3. 취합: 양식 맨 마지막 합본 시트가 모든 시트의 내용(표 포함)을 수식으로 자동으로 모읍니다. 합본 시트만 전체 선택(Ctrl+A)·복사해 [붙여넣기] 창이나 이 화면에서 Ctrl+V → 확인 창 → [가져오기]. 시트 이름을 바꾸거나 지워도 합본이 알아서 맞추고, 새로 만든 시트는 합본 맨 위 새로 만든 시트 이름 칸에 이름을 적으면 들어갑니다. 각 시트 A1에는 #시트 이름이 수식으로 저절로 들어갑니다.
  4. 인쇄: [인쇄 / PDF]. 화면으로 돌려 보게 하려면 저장 ▾ → 배포용 보기 파일.

입력 팁

  • Tab 들여쓰기, Shift+Tab 내어쓰기 (여러 줄을 선택해도 됩니다)
  • 목록 줄에서 Enter를 누르면 다음 기호가 자동으로 붙고, 빈 항목에서 한 번 더 누르면 목록이 끝납니다.
  • 엑셀에서 복사한 줄을 부서 입력칸에 붙여넣으면 - 시간 내용 @장소 형태로 바뀌어 들어갑니다.
  • 미리보기에서 부서를 클릭하면 그 부서의 입력칸으로 이동합니다.

저장 (재부팅해도 남기려면)

  • 파일로 저장하는 기능은 없습니다. 작업 중인 내용은 이 탭에만 자동으로 남아 새로고침해도 이어지고, 탭·창을 닫으면 지워집니다(이 컴퓨터에 남지 않음). 매일 한셀에서 복사해 붙여넣어 씁니다. 직위·성명·회사명·서식처럼 계속 쓸 것은 저장 ▾ → 매일 쓸 양식 파일로 받아 두고 그 파일을 여세요.
  • 매일 같은 부서·서식으로 시작하려면 저장 ▾ → 매일 쓸 양식 파일을 바탕화면에 두고 그 파일을 여세요.
  • 완성본을 화면으로 돌려 보게 하려면 저장 ▾ → 배포용 보기 파일을 보내세요. 링크와 설명 팝업이 동작합니다.

인쇄

  • 인쇄 창에서 용지 A4, 배율 기본값(100%), 여백 기본값으로 두세요. ‘PDF로 저장’도 됩니다.
  • 빨간 테두리가 보이면 한 장을 넘는 상태입니다. 서식 탭에서 최소 글자크기를 낮추거나 2단·가로로 바꿔 보세요.

한셀(엑셀)에서 복사한 내용 붙여넣기

시트 내용을 복사(Ctrl+C)해 아래에 붙여넣으세요. 여러 시트를 합쳐 붙일 때는 시트마다 맨 앞에 A열 한 칸짜리 #부서명 줄(양식에서는 각 시트 A1)이 있으면 부서별로 나눠 넣습니다(시트 안의 표도 그대로, 시트 사이는 한 줄 띄워도 됨). 한 시트만 붙이면 확인 창에서 부서를 고릅니다. 부서 열이 있는 한 시트도 됩니다. 자세한 규칙은 '입력 방법' 탭.
