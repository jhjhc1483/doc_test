수정 후

 2834     if ((m = /^\[(?!\[)(.+)\]$/.exec(t))) return m[1].trim();

다 고친 뒤 확인

  • 형광펜: 입력칸에 - 09:00 [[주간 업무보고]] 회의 @대회의실 → 미리보기에서 "주간 업무보고"만 노랗게, 시간·장소는 그대로. ==글==은 글자 그대로 보이면 맞습니다. 미리보기 위 [형광펜]으로 칠하면 입력칸에 [[ ]]가 생깁니다.
  • 붙여넣기: 한셀 칸에 [[주간 업무보고]]라고 쓴 줄을 붙여넣어도 시트 이름으로 착각하지 않고 일정으로 들어가면 됩니다.
  • 하위 줄: 서식 탭에서 "하위 줄 붙이기"를 보통 → 가깝게 → 아주 가깝게로 바꾸면 *·- 줄이 윗줄로 점점 붙습니다.
  • 칸 크기(임원): 경계를 끌면 마우스 옆에 mm가 나오고, 놓을 때까지 글자크기가 그대로입니다. 놓으면 알림에 [되돌리기]. 경계를 한 번 누르면 주황색이 되고 ←→로 움직입니다. 맨 밑 표의 이름 칸과 칸 사이에도 경계가 있습니다. 서식 탭 칸 크기에 mm 숫자 칸이 보입니다.
  • 표 폭(부서별): 내용에 표가 있는 부서에서 표 칸 사이를 끌면 폭이 바뀌고, 같은 머리글의 표를 다시 붙여넣어도 그 폭이 유지됩니다. 경계를 두 번 누르면 처음대로.
  • F12(개발자 도구) → Console에 빨간 오류가 없으면 됩니다.
